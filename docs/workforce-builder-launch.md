# AI Workforce Builder launch

The product page is `/ai-workforce-builder`. The price is USD 49 one-time. Sales remain closed until the server verifies the configured Stripe price and private ZIP.

1. Create or locate the Stripe product `AI Workforce Builder` and an active USD 49 one-time price in the correct account and mode. Set `AI_WORKFORCE_BUILDER_PRICE_ID` in Netlify Functions environment variables. Set `AI_WORKFORCE_BUILDER_MODE` to the matching `test` or `live` mode. Existing Stripe key, origin, tax and signed webhook settings are shared with Strategic Thinking. The existing webhook route handles both products.
2. Upload the unpersonalized v0.4.1 **Customer Package** ZIP (the outer ZIP including Start Here, guides, and the inner installable skill) to `paid-downloads` using `scripts/upload-strategic-thinking.mjs`, supplying private stdin JSON with `siteID`, `token`, `file` (absolute path) and `product` set to `ai-workforce-builder`. Never commit the ZIP or credentials. The script verifies the private upload and digest.
3. In Stripe, create a separate 100%-off coupon restricted to each intended Stripe product. Generate a private promotion code for each reviewer, with a maximum of one redemption. Never publish the code or create an unrestricted account-wide coupon. Confirm existing account-wide coupons do not unintentionally apply before enabling promotions.
4. Enable `AI_WORKFORCE_BUILDER_REVIEW_CODES=true` and `STRATEGIC_THINKING_REVIEW_CODES=true` only when the respective restricted promotions have been configured. Stripe applies codes on its hosted checkout; the server verifies completed zero-cost orders for the correct product, release and price, without requiring a charge that does not exist. Paid orders continue to require a successful unrefunded, undisputed charge.
5. In a Stripe sandbox and Netlify deploy preview, use test-only keys and prices, the exact preview origin, and a sandbox webhook endpoint. Keep them scoped to the deploy-preview context; never copy live credentials into previews. Enable the two test sales and review-code flags there alone. Test mode writes harmless fixture ZIPs into the separate `qa-paid-downloads` store and stores test orders separately; it cannot access the commercial archives. Confirm paid and 100%-off checkout, correct fixture download, duplicate webhook delivery, one-use code exhaustion and no payment-card requirement for the zero-cost purchase. Check that the private archive never appears in public assets. Do not make a live test charge.
6. After verification, set `AI_WORKFORCE_BUILDER_ENABLED=true` and deploy. The existing Strategic Thinking sales flag need not change. Redeploy after any environment changes. Verify status and a real reviewer redemption when authorized.
